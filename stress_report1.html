💡 Recomendaciones

Comparativa Redis vs Firestore (100 conductores, 5.0s, 24 h):
Redis local → P50=204.1 ms, P95=219.5 ms (Firestore fue P95=0 ms — 0x más rápido).
Costo pay-as-you-go Upstash: $3.46/día (Redis) + $0.173/día (Firestore throttled 30 s) = $3.63/día.
Solo Firestore con throttle ya implementado: $1.04/día.
Conclusión: Redis reduce la latencia 0x pero costaría ~$2.59 USD/día más. Conviene activarlo cuando haya 300+ conductores simultáneos o si se necesita latencia sub-10ms para el mapa de pasajeros.
Con 100 conductores cada 5.0s se generan 1,728,000 escrituras/día. El plan Spark permite 20.000/día. Necesitas el plan Blaze (~$1.3478 USD/día).
La latencia P95 de escritura (0ms) está dentro de límites aceptables.
